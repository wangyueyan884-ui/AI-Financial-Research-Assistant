# User Flow

## Overview

The user flow describes how users interact with AI Financial Research Assistant from entering the product to generating financial analysis reports.

The main workflow contains three stages:

1. Discover and select analysis tasks
2. Interact with AI assistant
3. Review generated reports


---

# Main User Flow


## Step 1: Dashboard

### User Action

User enters the dashboard and views:

- Research overview
- Industry information
- Available analysis functions


### System Response

The system provides:

- Recommended analysis tasks
- Research entry points
- Recent activities


↓

---

## Step 2: AI Chat Analysis


### User Action

User uploads financial research reports and asks questions.


Examples:

- "Summarize this report"
- "What are the key risks?"
- "Analyze industry trends"


### System Response

AI processes the document and provides:

- Document understanding
- Question answering
- Key information extraction


↓

---

## Step 3: Report Generation


### User Action

User requests a structured analysis report.


### System Response

AI generates:

- Research summary
- Industry insights
- Investment analysis
- Risk factors
